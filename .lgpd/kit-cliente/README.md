# Kit LGPD para clientes do StarX Kiosk

O cliente (empresa que usa os coletores com os seus colaboradores) é o **controlador** e tem estes deveres. O fornecedor entrega os modelos prontos. Isso reduz a barreira de venda e protege os dois lados. **Todos os modelos precisam da revisão do jurídico do cliente.**

| Dever do cliente | Modelo entregue |
|---|---|
| Ter base legal para o monitoramento (Arts. 7º e 10) | `bases-legais-modelo.md` + avaliações de legítimo interesse em `lia-modelos/` |
| Informar os colaboradores (Art. 9º) | `aviso-colaboradores-modelo.md` + tela de aviso no coletor (recurso do produto, em `../roadmap-produto.md`) |
| Ter Encarregado e canal (Art. 41) | `encarregado-orientacao.md` |
| Relatório de impacto do monitoramento (Art. 38) | `../RIPD/ripd-monitoramento-colaboradores.md` (modelo; alto risco provável) |
| Atender pedidos dos colaboradores (Art. 18) | `../dsar/workflow.md` + exportação/anonimização no painel (recurso do produto) |
| Comunicar incidentes (Res. 15/2024) | `../incidents/runbook.md` (adaptar) + aviso do fornecedor em até 24 h (cláusula 8 do `../vendors/dpa-cliente.md`) |
| Registrar as operações (Art. 37) | usar `../data-map.md` como base |

**Configurações que o cliente decide no painel** (são as instruções dele ao operador):
- quais coletores leem o SSW;
- se a localização fica ligada;
- quem acessa os indicadores individuais;
- prazos de guarda (quando configuráveis).

**Recomendações que valorizam o produto na venda**:
- localização desligada por padrão;
- indicadores individuais visíveis só a quem precisa;
- nenhuma punição baseada só nos números do sistema.
